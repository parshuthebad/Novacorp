# Submission checklist

## Submission form
- [ ] Fill in **all** required fields.
- [ ] **Do not change the auto-generated UUID.**
- [ ] Check your name and email ID are correct.
- [ ] Add a working **open-access video link** (see below).

## Video link rules
- Google Drive: set access to **Anyone with the link - Viewer**, or use any platform with a public link.
- Private, restricted or permission-based links are **not evaluated**. Open the link in a private/incognito window to verify.
- Recommended length: **5-10 minutes**.

## Video must cover (suggested script, about 8 minutes)
| Time | Section | What to say and show |
|---|---|---|
| 0:00-1:00 | Problem statement | Priya at NovaCorp types 50 customers from Excel into a web portal every Monday. It takes 3+ hours and has typos. |
| 1:00-2:30 | Automation idea and use case | Why it fits RPA: repetitive, rule-based, structured data. Only the South region is onboarded. It scales from 50 to 500. |
| 2:30-6:00 | Bot flow overview | Show the TaskBot: Read Excel, Loop Rows, Check Region (If), Web Entry (Recorder), Try/Catch for duplicates, Log Result. Mention variables, validations and the 4 layers. |
| 6:00-7:30 | Final output / result | Run the bot. Show the portal entries, the log file (Done / Failed / Skipped), the duplicate being caught without crashing, and the report. |
| 7:30-8:00 | Wrap-up | What you learned and what you would add next. |

## Before you record
- [ ] Bot Agent shows Connected and the TaskBot runs end to end.
- [ ] Test with 2-3 rows, then a duplicate, then all 50.
- [ ] Log file and report open and look correct.
